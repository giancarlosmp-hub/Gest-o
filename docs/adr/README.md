# Registros de Decisão Arquitetural

Este diretório conterá os *Architecture Decision Records* (ADRs), destinados a registrar o contexto, as alternativas e as consequências das decisões arquiteturais relevantes.

Cada decisão deverá ser vinculada ao [Documento Mestre](../DOCUMENTO_MESTRE.md) quando fizer parte do contexto consolidado do projeto.
